# 产品预期

## 定位与使用对象

pakka-ei 是 Pakka's environment infrastructure，面向个人使用的 Agent 运行时提供执行环境基础设施。产品围绕环境的取得与释放、执行权限、能力调用及资源生命周期组织。

可信宿主选择目标及授权，环境按绑定的策略提供能力。上层会话、任务和应用编排通过公开接口使用环境；这些业务对象的管理由各自运行时承担。

## 组件与职责

| 对象                           | 职责                                                         |
| ------------------------------ | ------------------------------------------------------------ |
| 环境使用方                     | 批准工作目录和权限，取得环境，将能力绑定到调用，处理释放结果 |
| [MXC 文件 owner](mxc-files.md) | 拥有受限文件进程、真实文件句柄、临时数据和关闭过程           |
| 文件能力接口                   | 通过异步方法和冻结结果传递路径、文件元数据与内容             |
| 运行时适配                     | 将环境能力接入运行时的公开执行接口，维持调用范围和资源归属   |

组件的能力集合、运行条件、失败含义与权限边界由对应后端契约描述。

## 项目与集成关系

- pakka-ei 拥有独立源码仓库、发布周期和维护入口，包名为 `@pakka/ei`。
- 环境核心通过中性数据和能力方法提供接口，运行时依赖限于具体环境后端。
- Pakka 是环境能力的使用方；文件 owner 可结构兼容其部分 `ExecutionDriver`，由可信 bootstrap 通过执行配置注入。
- 文件名字空间、环境 owner、调用范围各有独立身份与寿命。共享宿主文件名字空间的多个 owner 仍分别拥有权限、进程和临时资源。
